          About this demo

          Digital Investigation & Evidence Management System

          Every case has a trail. Every piece of evidence has a history.

          This is the initial frontend prototype of a B.Tech CSE (AI/ML) DBMS capstone project. It is built with HTML, CSS and vanilla JavaScript.

          • All data is fictional demonstration data.
          • There is no backend or database yet. Changes are kept in temporary browser storage (localStorage) so they survive a refresh.
          • Custody entries are simulated and are not forensic verification.
          • Planned stack: Node.js, Express.js and MySQL.
